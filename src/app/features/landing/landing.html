El espectáculo en vivo no admite fallas de red ni caídas de servidor. Arquitectura desacoplada y tolerante a fallos.

SEGURIDAD & IDaaS

Microsoft Entra ID

Autenticación federada corporativa mediante MSAL Angular 6.2 y JWT Authorizer en AWS API Gateway. Control de acceso estricto por roles (Admin, Productor, Organizador, Auditor).

issuer: login.microsoftonline.com · MSAL v6
COLAS DE TRABAJO

RabbitMQ 4.3 Async Dispatch

Cola q.cmd.crew para tickets de montaje y notificaciones transaccionales a organizadores. Desacoplamiento total con colas durables y dead-letter exchange (DLQ).

exchange: cmd.direct · AMQP 0-9-1
STREAMING DE EVENTOS

Apache Kafka 7.8 Cluster

Topic productions.events y audit.timeline con 3 brokers y persistencia distribuida. Analítica de KPIs operacionales y timeline de auditoría forense con acuse ACK=all.

replication-factor: 3 · partitions: 3 · Outbox Pattern
MICROSERVICIOS & UI

Spring Boot 4.1 + Angular 22

Microservicios de dominio (productions, catalog, notify, audit, report, bff) con persistencia PostgreSQL 17 y frontend de alta reactividad con Signals.

Java 25 (Temurin) · PostgreSQL 17 ACID · Angular Signals
